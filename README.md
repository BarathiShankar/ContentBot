# Smart Content Summarizer 📝⚡

A **React + Firebase web application** that empowers users to generate, refine, and store text summaries using AI.  
Built with a sleek **black + orange theme**, the app provides an interactive dashboard, summary history, and user authentication.

---

## 🚀 Features
- **AI‑powered summarization**: Generate concise summaries from any input text.
- **Refinement modes**: Expand, simplify, or transform summaries into essays.
- **User authentication**: Secure login and registration with Firebase Auth.
- **Summary history**: Automatically saves summaries to Firestore under each user’s account.
- **Interactive UI**: Animated buttons, glowing effects, and responsive design.
- **Loading screens**: Full‑page black + orange overlay during login and summarization.

---

## 🛠️ Tech Stack
- **Frontend**: React, React Router, React Markdown
- **Backend**: Firebase (Auth + Firestore)
- **AI Integration**: Custom Gemini API functions (`summarizeText`, `refineSummary`)
- **Styling**: CSS animations, black + orange theme
